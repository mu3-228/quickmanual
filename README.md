# QuickManual

店舗業務で使用するマニュアルを管理するためのWebアプリです。

## 概要

QuickManualは、店舗スタッフが業務マニュアルを素早く確認できるようにすることを目的として開発したアプリです。

通常業務の手順だけでなく、トラブルやイレギュラーな事象が発生した際にも必要な情報へ素早くたどり着けることを目指しています。

## 開発のきっかけ

アルバイト先で使用していたマニュアルアプリに使いづらさを感じたことが、このアプリを作ろうと思ったきっかけです。

既存のマニュアルは通常業務の手順を確認することはできましたが、イレギュラーな事象が発生した際に必要な情報へたどり着きにくいという課題がありました。

そこで、「困ったときにすぐ解決へ近づけること」と「現場で本当に役立つこと」を意識し、かゆいところに手が届くマニュアルアプリを目指して開発しました。

## 使用技術

* Python 3.12
* Django 5.1
* PostgreSQL
* Git / GitHub

## 主な機能

* マニュアル一覧表示
* マニュアル詳細表示
* カテゴリ管理
* Django管理画面からのデータ登録

## 工夫した点

* DjangoのClass Based View（CBV）を使用して実装
* PostgreSQLを利用したデータ管理
* GitHubによるバージョン管理
* .envによる機密情報（SECRET_KEY・DB設定）の管理
* 現場での利用を想定し、シンプルで素早く情報へアクセスできる構成を意識

## 今後追加したい機能

* キーワード検索機能
* カテゴリによる絞り込み機能
* イレギュラー対応FAQ機能
* お気に入り登録機能
* 修理業者や各種連絡先をまとめた連絡先ページ
* 店舗スタッフごとの権限管理機能

## 今後の展望

通常業務のマニュアル管理だけではなく、機器トラブルやクレーム対応などのイレギュラーな事象が発生した際にも、必要な情報へ素早くたどり着けるアプリを目指しています。

将来的には、FAQや連絡先情報を集約し、「困ったときにまず開くアプリ」として活用できるサービスへ発展させたいと考えています。
